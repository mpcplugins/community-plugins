# Community MPC Plugins

**Hosted by The Disk King** · [thediskking.com/plugins](https://thediskking.com/plugins/)

Plugins for the Akai MPC and Force made by people who don't use GitHub. Makers upload them at
**[thediskking.com/plugins/share](https://thediskking.com/plugins/share/)**; each one is checked (checksum, MPC
processor, risky functions) and approved by hand before it is published here as a release, with its maker's name.

Every release here is listed automatically on [thediskking.com/plugins](https://thediskking.com/plugins/),
[mpcplugins.github.io](https://mpcplugins.github.io/) and in **MPC Plugins Manager** on the MPC.

## Get updates automatically

[![Get updates with MPC Plugins Manager](assets/updates-button.png)](https://mpcplugins.github.io/p/mpc-plugins-manager/)

A zip you download by hand **never updates itself**. Install **[MPC Plugins Manager](https://mpcplugins.github.io/p/mpc-plugins-manager/)** once on your MPC: it shows when a new version of any plugin here is out and installs it in one tap. It is the only way to get updates without checking back here.

## Install a plugin from here

1. Your MPC needs MPC OS 3.10.1 with **Enable Enhancements** and **External Plugin Support** on (Menu → Preferences → Enhancements).
2. Download the plugin's `...-mpc-sdk.zip` from [Releases](../../releases), unzip it, and copy the `Maker - VST - Name` folder into `VST2 Plugins` on your MPC. Restart.
3. Or install it in one tap with [MPC Plugins Manager](https://github.com/mpcplugins/mpc-plugins-manager).
