MPC Plugin Scanner 1.0.0 by The Disk King

A safety check for the plugins on your MPC, running right on the MPC. Add it on a plugin track: it checks every plugin in every VST2 Plugins folder (internal, SSD, USB) and gives each one a light with the reasons.

- 🔴 **RISKY**: running other programs or shell commands, delete-everything / disk-erasing commands, download commands, hidden scripts or programs, system drivers, back doors, reading passwords, changing system rights or setup, restarting the MPC, links outside its folder.
- 🟡 **CHECK**: uses the internet, starts background tasks, stops other programs.
- 🟢 **CLEAN**: no warning signs (normal file use is only a note).
- Tap a plugin for all its reasons. SCAN AGAIN, PREV / NEXT.
- Changes nothing, runs nothing, sends nothing anywhere. Makes no sound. Does not list itself.

A warning-sign scan, not a guarantee: cleverly written code can hide what it does. Tested on an Akai MPC Live III, MPC OS 3.10.1.

Install: copy `The Disk King - VST - MPC Plugin Scanner` into `VST2 Plugins` on your MPC's internal drive (MPC OS 3.10.1+, Enhancements and External Plugin Support on), or install it with MPC Plugins Manager.
