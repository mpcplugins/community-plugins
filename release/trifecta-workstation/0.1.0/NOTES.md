Trifecta Workstation 0.1.0 by The Disk King

A 2000s-style music workstation for the MPC: silver panel, blue touch-screen display, realtime knobs and a VALUE dial.

**Early beta.** Tested on an Akai MPC Live III, MPC OS 3.10.1.

- The Disk King's PRELOAD set included: 512 programs and 512 combis in banks A-D, shown by name. Select by tapping the list, turning the VALUE dial, PREV / NEXT, bank keys and PROG / COMBI.
- Trifecta Voice: built-in analog-style synth (2 detuned oscillators, sub, noise, 24 dB filter with envelope, amp envelope, LFO). In 0.1 every program plays this voice.
- Realtime knobs (Cutoff, Resonance, EG Int, Release), SW1 mono, SW2 portamento.
- Arpeggiator (Up, Down, Alt 1, Alt 2, Random, 1/8-1/32, gate, octaves, swing, latch; follows the MPC tempo).
- Chorus, tempo delay, reverb. KEYS page with 61 keys that light from the pads.

Install: copy `The Disk King - VST - Trifecta Workstation` into `VST2 Plugins` on your MPC's internal drive (MPC OS 3.10.1+, Enhancements and External Plugin Support on), or install it with MPC Plugins Manager.
